# ПроБрови — демонстрационный сайт

Адаптивный одностраничный сайт студии красоты «ПроБрови» в Королёве.

## Предпросмотр

После включения GitHub Pages по схеме **Settings → Pages → Deploy from a branch → main / (root)** сайт будет доступен по адресу:

https://proninmike3-cyber.github.io/probrovi/

## Состав

- `index.html` — готовый самостоятельный сайт со встроенными CSS, JavaScript и SVG-иконками.
- Онлайн-запись ведёт на действующую страницу DIKIDI.
- Прайс и контакты взяты из открытых источников для демонстрации. Перед коммерческой публикацией цены и право на использование фотографий необходимо согласовать с владельцем.

Админ-панели и серверной части нет.
